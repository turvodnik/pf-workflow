# Шаблон реестра автопилота (.agents/runtime/autopilot-run.md)

Используется, когда компаньон pf-handoff не установлен (иначе реестр живёт в HANDOFF). Перезаписывается на каждом событии: волна запущена, сводка принята, вердикт ревью, раунд фикса, стоп.

```markdown
# Реестр автопилота · <проект> · <дата>

Параметры: fix_rounds=3, parallel=2, batch=1–3. BASE волны <N>: <sha>.

| Задание | Тикеты | Субагент (модель) | Статус |
|---|---|---|---|
| A (волна 1) | T-001, T-002 | pf-executor (sonnet) | запущен / сводка принята / гейт: ЧИСТО|замечания / фикс-раунд N/3 / done / blocked |
| B (волна 1) | T-003 | pf-executor (sonnet) | … |
| C (волна 2) | T-004 | — | ждёт A; [стоп-граница: <какое внешнее действие>] |

## Запарковано (💭 — решает финальный ревью/отчёт)
1. <замечание> — <откуда>

## Стопы
- <время> · <причина стопа> · <что подготовлено> · ждёт человека
```
